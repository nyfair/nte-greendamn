# Yet Another Neverness to Everness Censorship Remover and Mod Loader

## Key Features

- **Censorship Remover** — zeroes the fade/hide distances and the fade curves on the camera manager, so the character stays visible no matter how close the camera gets.
- **Mod Loader** — put mod files into `Client\WindowsNoEditor\HT\Binaries\Win64\~mods` folder in the games file directory.
- **Tiny and idle** — No CPU/GPU/Memory usage.

## How to use

### Method 1 — Ultimate ASI Loader

1. Download [`winmm-x64.zip`](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases/download/x64-latest/winmm-x64.zip).
2. Put `winmm.dll` (from the zip) and `nte-greendamn.asi` into the game folder.

### Method 2 — OptiScaler

1. Download and install `OptiScaler` , then rename `OptiScaler.dll` to `winmm.dll`.
2. Set `LoadAsiPlugins=true` in `OptiScaler.ini`.
3. Create an `OptiScaler\plugins` folder and put `nte-greendamn.asi` inside it.

### Method 3 — Your Preferred ASI Loader

Load `nte-greendamn.asi` with whatever ASI loader you already use.

## 功能特色

- **反河蟹** —— 清零相机管理器上的淡出/隐藏距离和淡出曲线，相机贴得再近，角色也不会淡出或被隐藏。

### 方法 1 —— Ultimate ASI Loader
